## 📋 Full Screenplay Master Prompt

```
Generate a full [7 / 10 / 15]-minute screenplay for my Storiyum channel based on this story:
[PASTE YOUR STORY TOPIC/ONE-LINER HERE]

Requirements:
1. Do NOT include channel intro/outro — story content only
2. Break it into ~20-30 scenes (~20 sec each) to match the total runtime
3. Create a CHARACTER & STYLE LOCK section at the top:
   - Full physical description of EVERY main character (age, face, hair, outfit, build) —
     detailed enough to stay visually identical across all images
   - A style lock (art style: photoreal/cinematic/animated — specify genre mood)
   - A location lock (all key recurring settings)
4. For EVERY scene give me a table with:
   - Scene number + timestamp
   - Hinglish voiceover (natural, spoken storytelling tone, not textbook Hindi)
   - Sound/effect cue (SFX, silence beats, music shifts)
   - Full image prompt that starts with "[CHARACTER REF]" and always re-includes the
     character/style/location lock before the scene-specific detail
5. Add sections at the end for:
   - Voiceover direction (pacing, tone shifts, voice layering for ghost/villain/flashback voices)
   - Music & SFX map (per scene range)
   - Transition & effect notes for smooth rendering (cuts vs cross-dissolves, flashback
     treatment, color grade arc)
   - A tip on using image-to-image/reference-image consistency for the rendering tool
6. Also give me: Title (3 options + your pick), full YouTube description with hashtags and
   timestamps, and a thumbnail prompt with text overlay suggestion

Genre: [thriller / horror / emotional / suspense — pick one or mix]
Tone:  [e.g. slow-burn dread, tearjerker, twist-ending, chase-thriller, etc.]
```

## 🎞️ 25-Second Teaser / Reel Master Prompt

```
Create a 25-second vertical (9:16) teaser/reel for this full story: [STORY TITLE]

Requirements:
1. Use the SAME character reference lock from the full screenplay — do not change appearance
2. 5 scenes only, building suspense fast:
   - 0–5s   : hook
   - 5–15s  : rising tension
   - 15–20s : peak dread
   - 20–25s : cliffhanger cut
3. NEVER reveal the ending, twist, or resolution — cut right at the most tense unresolved moment
4. Include: Hinglish VO (sparse — some scenes can have NO voiceover, just text on screen
   for impact), SFX/silence cues, and full image prompt with [CHARACTER REF]
5. End with on-screen text directing to:
   [choose one] "comment 'STORY' for the link"  OR  "full video — link in bio"
6. Give me a caption + hashtags for Instagram/YouTube Shorts
7. If using comment-to-link method, also give me the pinned comment text
```
